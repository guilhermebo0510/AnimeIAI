# 02 — Workspaces

A barra no alto agrupa os workspaces. Cada um tem um arranjo de painéis próprio, que você pode rearrumar (arrastar abas, soltar painéis flutuantes) e restaurar ao padrão de fábrica pelo menu Janela.

| Grupo | Workspace | Para quê |
|---|---|---|
| Pré-produção | **Roteiro** | cenas, falas e personagens; o roteiro alimenta beats, storyboard e as falas do áudio |
| | **Personagens** | pasta de cada personagem (model sheet, turnaround, expressões, paleta de settei) e canvas para desenhar nesses materiais |
| | **Storyboard** | prancha de painéis (e-conte), tempo de cada painel, animatic em vídeo e *Gerar cortes* |
| Arte | **Layout** | layout do corte com guias 3D, réguas de perspectiva e referência do personagem |
| | **Cenário** | fundos: pincéis de cenário, texturas, céu, padrão em perspectiva |
| | **Animação** | genga e douga (variante Douga), linha do tempo, mesa de luz (onion skin), intercalação, timesheet |
| | **Pintura** | pintura das células com balde e paleta indexada; *Verificar* aponta buracos e cores fora da paleta |
| Finalização | **Composição** | satsuei: camadas, efeitos (brilho, desfoque, partículas…), câmera multiplano, grade de cor e LUT |
| Recursos | **Biblioteca** | acervo de pincéis, paletas, texturas, modelos 3D e materiais reutilizáveis entre projetos |
| | **Modelagem** | modelagem 3D simples de adereços e manequins como referência de desenho |
| Som e montagem | **Áudio** | falas (VOICEVOX/Kokoro), lip-sync, efeitos sonoros, BGM, mixagem e loudness (−24 LKFS) |
| | **Edição** | montagem dos cortes, transições, legendas, créditos e prévia com som |
| | **Entrega** | fila de exportação (MP4, ProRes 4444, PSD/ORA, XDTS, SVG, OpenTimelineIO, .srt) e verificação final |
| Gestão | **Produção** | quadro de cortes por etapa, correções, retakes e relatório de produção |
