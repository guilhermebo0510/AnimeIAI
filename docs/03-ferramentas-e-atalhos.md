# 03 — Ferramentas e atalhos

Os atalhos abaixo são os padrões; todos podem ser trocados em *Preferências → Atalhos*.

## Ferramentas do canvas

| Tecla | Ferramenta | Notas |
|---|---|---|
| B | Pincel | pincéis raster com pressão, curva de pressão, texturas e presets; `[` e `]` diminuem/aumentam o tamanho |
| P | Caneta vetorial | traço nítido em qualquer zoom; linha, curva e formas; respeita a seleção |
| Y | Editar pontos | edição de nós do vetor: `.`/`,` próximo/anterior, C canto, Shift+C alça automática, Delete apaga |
| E | Borracha | raster ou vetorial (por trecho/interseção) |
| G | Balde de tinta | fecha frestas da linha; pode preencher só o que ainda não está pintado |
| M | Seleção (laço) | menu *Selecionar*: tudo, inverter, expandir, encolher, faixa de cor |
| W | Seleção automática (varinha) | |
| J | Mistura | |
| I | Conta-gotas | mantém a cor ligada à paleta |
| K | Mover | alças de escala/rotação; Ctrl + canto = distorção livre; malha |
| T | Texto | |
| U | Régua | Shift+U próxima régua; Ctrl+; mostra as réguas; Ctrl+Shift+; encaixa |
| H / Z | Pan / Zoom | Ctrl+0 ajusta à janela; Ctrl+1 tamanho real |
| Shift+M | Modelo 3D | |

## Animação

| Tecla | Ação |
|---|---|
| ← / → | quadro anterior / próximo |
| Home / End | primeiro / último quadro |
| Ctrl+← / Ctrl+→ | chave anterior / próxima |
| Alt+← / Alt+→ | desenho anterior / próximo |
| O | liga/desliga a mesa de luz (onion skin) |
| Shift+K | alterna o papel da célula (chave, intercalação…) |
| Ctrl+Shift+T | densidade da linha do tempo |

## Arquivo e edição

Ctrl+N novo · Ctrl+O abrir · Ctrl+S salvar · Ctrl+Shift+S salvar como · Ctrl+Z desfazer · Ctrl+Shift+Z refazer.
