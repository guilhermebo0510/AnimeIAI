# Mapa de ferramentas

Catálogo do que o programa precisa ter, por fase de produção. **MVP** = obrigatório para a calibração e o micro anime; **P1** = importante, entra se não bloquear o MVP; **P2** = depois. Referência = programa cujo funcionamento é estudado (engenharia reversa de comportamento, não de código).

Toda ferramenta MVP precisa de: comando no Command Bus, exposição no MCP, UI utilizável por mouse, teste e evidência visual.
